The Six Sophos Log Types

Sophos XGS generates six distinct log types. Each is written to a different log stream and contains different fields. Knowing which log type to look at first saves significant time during investigations.

Sophos Log Types and What They Cover
Start with the Firewall log to scope the incident. Use IPS logs for attack confirmation. Use SSL logs for C2 detection. Use App Control for exfiltration tools.

Reading a Sophos Firewall Policy Log

The firewall policy log records every connection that matched a firewall rule, whether it was allowed or denied. This is the most detailed view of network activity at the perimeter.

Sophos Firewall Log - Allowed Connection (potential exfiltration)
date=2026-09-20 time=10:30:01 device_name="SophosXGS-HQ" log_id=010302600001 log_type="Firewall" log_subtype="Allowed" policy_type="Network Policy" rule_id=4 rule_name="LAN-to-WAN" src_ip=10.0.1.10 src_mac=00:1A:2B:3C:4D:5E dst_ip=185.220.101.45 dst_port=443 protocol=TCP sent_bytes=98442 recv_bytes=1204 duration=44 user_name="-"
Reading This Log for Exfiltration Signs
sent_bytes=98442 (96 KB sent out) versus recv_bytes=1204 (1.2 KB received). A normal HTTPS connection to a website sends a small request and receives a large response. This is reversed: large data going out, small response coming back. That asymmetry, combined with an unknown external IP (185.220.101.45), is a strong exfiltration indicator. The session lasted 44 seconds. Check this IP in SafeLine WAF logs, then in threat intelligence.

Key Takeaways

  • Sophos produces six distinct log types: Firewall, IPS, SSL, Web Filter, Application Control, and Event. Start with Firewall for scoping, add IPS for attack confirmation, add SSL for C2 domain discovery.
  • The sent_bytes vs recv_bytes ratio in Firewall logs is one of the most reliable exfiltration indicators. Normal web browsing has low sent/high received. Exfiltration has high sent/low received.
  • IPS logs include a signature_id that maps to a detailed threat description and often a CVE number. Always look up the CVE to understand the vulnerability being exploited.
  • SSL logs provide the SNI (hostname) of every TLS connection even without decryption. This is your primary tool for C2 domain detection when SSL inspection is not enabled.
  • Multi-log correlation across IPS, Firewall, and SSL logs is the standard method for reconstructing the full attack timeline in a Sophos environment.
