The Learning Journey

This course moves you through four phases. Each chapter builds on the last. By the end you will be able to collect, read, correlate and act on real network evidence using professional security tools.

Course Learning Path
The course builds progressively from understanding traffic to running a full incident investigation.

Your Tool Stack

These are the real tools you will use throughout the course. Each chapter shows you what that tool sees during normal and attack traffic.

Sophos Firewall
Perimeter defence, IPS, packet capture, traffic flow logs, threat feed correlation.
SafeLine WAF
Web application firewall. Detects and blocks SQLi, XSS, path traversal, and other Layer 7 attacks.
Wazuh
Open-source IDS and SIEM. Ingests logs from agents, matches rules, fires alerts, runs active response.
Grafana
Observability and dashboarding. Visualises metrics from all tools, fires alerts when thresholds are breached.
Kali Linux
Controlled offensive platform. Used to generate realistic attack traffic so you can see what defenders observe.
Bettercap
MITM framework. ARP spoofing, HTTP sniffing, HTTPS stripping, DNS spoofing and more.
